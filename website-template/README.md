# Hackathon design-reference library

Captured from the local Brave bookmark folder `hackathon / design-inspo` on 2026-09-04.

The tracked URL inventory is [reference-websites.txt](reference-websites.txt).
Reference PNGs remain available locally for visual inspection but are ignored
by Git; only final prototype QA images are tracked.

The workflow instruction snapshots are documented in [skills/README.md](skills/README.md).

Each style is organized as:

```text
<style>/<tab>/images/desktop.png
<style>/<tab>/images/mobile.png
```

The desktop viewport is 1440×900 and the mobile viewport is 390×844. Images are full-page captures of the embedded TypeUI preview route. The available preview tabs were clicked from the TypeUI design-skill page before capture.
